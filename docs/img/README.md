# Images

Screenshots and diagrams used by the docs live here. Reference them from Markdown
with a **relative path**, e.g. from the repo root README:

```markdown
![ShopDeck library view](docs/img/library.png)
```

or from a file inside `docs/`:

```markdown
![ShopDeck library view](img/library.png)
```

Keep images reasonably small (PNG, ideally < ~500 KB each) so the repo stays light.
